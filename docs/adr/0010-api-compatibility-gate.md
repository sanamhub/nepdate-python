# ADR-0010: API compatibility gate

- Status: Accepted
- Date: 2026-10-18
- Deciders: Sanam Pakuwal
- Amends: ADR-0004 (adds gate 10)

## Context

The public surface is defined by `nepdate.__all__` and `nepdate_patro.__all__`, and documented
in `docs/API.md`. Nothing checked that a release kept its names, signatures, enum values or
exception bases. A renamed method or a changed default is a breaking change that a normal test
suite may not notice, because the tests usually call the new name.

The P8 review also found a private parameter that no caller needed. A compatibility gate should
make the difference between private and public changes visible before a release.

## Decision

1. The snapshot is `docs/api-snapshot.json`, generated by `scripts/api_snapshot.py` with
   `inspect`. It records the public names, constructor and method signatures, property and class
   attribute annotations, enum members and values, class bases and the values of `MIN` and `MAX`.
   The JSON has sorted keys and a fixed schema. The 2026-10-18 baseline has 173 items and 19,845
   bytes.
2. `--write` regenerates the snapshot. `--check` compares the installed surface with the
   committed file. A removed or changed item fails. An added item fails unless `docs/API.md`
   shows its declaration: a `def` line with the same signature (ignoring whitespace and quotes),
   a `name: type` line for a property, attribute or constant, an enum member line with its value,
   or a `class` line. A name in prose is not a declaration.
3. Gate 10 of `scripts/ci.py` runs `--check`. The last line becomes `ci: 10/10 gates passed`.
   The gate runs on every supported Python version in the existing CI matrix, so a
   Python-version-dependent signature is caught.
4. A public change is a deliberate edit to the snapshot and `docs/API.md` in the same pull
   request. Private names are outside the snapshot, so their removal does not need a docs change.
5. ADR-0004 and the other accepted ADRs are not edited. This ADR records the tenth gate and the
   rule.

## Consequences

- A release cannot drop or rename a public name without a failing check.
- The snapshot is a review aid: its diff shows the public change in one place.
- The gate does not check behaviour, only the surface. Behaviour stays with the specs, vectors,
  properties and fuzzing.
- A tool upgrade or a new Python version that changes `inspect` output needs a deliberate
  snapshot update. The generator avoids module addresses and enum reprs so this should be rare.
