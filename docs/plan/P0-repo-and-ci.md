## Tasks

### P0-01 `pyproject.toml` files (uv workspace)
Root `pyproject.toml` (core and workspace root): `[project]` name `<core-name>`, `version = "0.0.0"`,
`requires-python = ">=3.11"`, license `MIT` (SPDX expression,
`license-files = ["LICENSE", "shared/data/NOTICE"]`), classifiers including `Typing :: Typed` and
`Programming Language :: Python :: Free Threading`, dependency `tzdata; sys_platform == "win32"`.
`[build-system]` `uv_build`; `[tool.uv.build-backend] module-name = "nepdate"`.
`[tool.uv.workspace] members = ["packages/nepdate-patro"]`. `[dependency-groups]` `dev` (ruff, mypy,
pytest, pytest-cov, hypothesis) and `bench` (P5). Tool config for ruff, mypy (`strict = true`) and
pytest (register the `slow` marker) in the root file. `src/nepdate/__init__.py` with a module
docstring, and `src/nepdate/py.typed`.

`packages/nepdate-patro/pyproject.toml`: name `nepdate-patro`, the same version and
`requires-python`, license `MIT` with `license-files = ["LICENSE", "NOTICE"]`, `[build-system]`
`uv_build`, `module-name = "nepdate_patro"`, dependency `"<core-name>>=0.0,<0.1"`,
`[tool.uv.sources] <core-name> = { workspace = true }`. PEP 639 doesn't allow `..` in
`license-files`, so `packages/nepdate-patro/LICENSE` and `NOTICE` are copies of the root `LICENSE`
and `shared/data/NOTICE`, written by `scripts/codegen.py` (P0-02) and checked by `--check`.
`packages/nepdate-patro/src/nepdate_patro/__init__.py` with a module docstring only, and `py.typed`.

`CHANGELOG.md` with an empty `## [Unreleased]` (one changelog for both distributions).

AC:
- `uv sync --all-packages` then `uv run python -c "import nepdate, nepdate_patro"` exits 0.
- `uv build --all-packages` writes two wheels and two sdists into `dist/`.
- `uv lock --check` passes (the lock file is committed).

### P0-02 Generator skeleton (`scripts/codegen.py`)
Reads `shared/data/calendar/bs-calendar.json`, checks 299 years × 12 lengths in 29..=32, writes
`src/nepdate/_calendar.py` starting with `# Generated by scripts/codegen.py. DO NOT EDIT.` and, for
now, `MIN_YEAR = 1901`, `MAX_YEAR = 2199`. It also copies `LICENSE` and `shared/data/NOTICE` into
`packages/nepdate-patro/` (P0-01). Output is deterministic (same bytes on every run and OS,
`\n` line endings) and passes `ruff format --check`.
AC: running it twice gives identical files; `--check` exits 0 right after a run and 1 after a byte of
`_calendar.py` is changed; a test feeds it a copy of the JSON with one length set to 33 and expects
a non-zero exit.

### P0-03 CI script (`scripts/ci.py`)
Runs the 7 gates in ADR-0004 in order, printing each command, stopping at the first failure, ending
with one summary line (`ci: 7/7 gates passed`, or `ci: gate N (<name>) failed`). Gates 6 and 7 create
their venvs in a temporary directory (`tempfile.TemporaryDirectory`) with `uv venv` and
`uv pip install --python <venv>`. Subcommand `release-check X.Y.Z` (P5-03).
AC:
- exits 0 and prints `ci: 7/7 gates passed` on a clean checkout;
- exits non-zero when a file is not formatted;
- the gate 6 content check is a function (`_archive_contains(path, needle) -> bool`, for `.whl`
  and `.tar.gz`) with unit tests on two small archives built in the test, one with the string and
  one without;
- runs on Windows (no shell built-ins, no `unzip`, no `grep`).

### P0-04 Test scaffolding
`tests/conftest.py` with a fixture that returns the repository root (found by walking up from
`__file__` to the directory holding `shared/VERSION`), and a helper that reads a TSV or CSV from
`shared/spec/vectors/`. `packages/nepdate-patro/tests/conftest.py` with the same root fixture.
One smoke test in each suite.
Tests for `scripts/codegen.py` and `scripts/ci.py` go in `scripts/tests/` and load the script
with `importlib.util.spec_from_file_location` (`scripts/` is not a package); they run in gate 3 only.
AC: `uv run pytest tests packages/nepdate-patro/tests scripts/tests` passes from the repository
root, and `uv run pytest` started inside `tests/` still finds `shared/spec/vectors/`.
